# Changelog

## [0.1.0] - 2024-11-10

### Added
- Initial release
- Sidebar TreeView with sync status indicators
- File explorer decorations (badges + colors)
- Status bar integration with sync summary
- Sync single file, folder, or all workspace
- Context menu integration (explorer + editor)
- Rich markdown tooltips with full page info
- Two view modes: By Folder / By Status
- Confluence REST API integration for version tracking
- Remote version comparison (detect newer remote versions)
- Automatic refresh on file changes
- Periodic remote version checks
- Configuration wizard with connection test
- mark CLI availability check
- Support for HTML comment headers and YAML frontmatter
- Custom theme colors (synced, modified, not-synced, no-metadata, syncing)
